# 📱 Children's Rights Awareness App

An interactive Android application built using Kotlin that aims to educate children about their fundamental rights through fun games, quizzes, and engaging content.

---

## 🌟 Features

- 🧒 **Know Your Rights** – Illustrated list of children’s rights explained in simple language.
- 🎮 **Play & Learn** – Mini-games and quizzes for interactive learning.
- 📈 **Progress Tracker** – Monitors the user's learning journey.
- ⏰ **Right of the Day** – Daily reminders with bite-sized rights info using notifications.
- 📅 **Custom Reminders** – Let users set reminders using date/time pickers.
- 🔔 **Notification System** – Scheduled alerts via AlarmManager and Notification Channels.
- 🗂️ **Data Storage** – Stores user data using Shared Preferences and Internal Storage.
- 🔐 **Child-friendly UI** – Bright visuals, large buttons, and simple layout.
- 🔄 **Navigation Drawer & Tabs** – Easy navigation using Fragments and ViewPager.

---

## 🛠️ Tech Stack

### Front-End:
- **Language:** Kotlin
- **UI Components:** ScrollView, Toolbar, RatingBar, Custom Toasts, ProgressBar, Navigation Drawer, ViewPager with Tabs, Fragments, Pickers, Custom Views

### Back-End:
- **Data Storage:** Shared Preferences, Internal & External Storage
- **App Communication & Scheduling:** Intents, PendingIntents, AlarmManager, JobScheduler, Notification Channels
